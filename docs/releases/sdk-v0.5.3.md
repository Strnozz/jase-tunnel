## Companion desktop 0.3.5

This SDK package accompanies desktop 0.3.5, which updates the Jase logo on all platforms, uses the white J and jay silhouette in the macOS menu bar, and refreshes the Windows panel.

The SDK protocol, adapters, CLI and Safari transport are unchanged from 0.5.2. Existing integrations remain compatible. The package README now explains the desktop update and distinguishes npm's website SDK from the separately downloaded desktop app.

The website download catalog selects the new desktop executables after the GitHub desktop release is published. This npm package is staged for owner approval; it becomes available through the registry only after that approval.
