## Jase desktop identity and Windows panel

Windows, macOS and Linux now use the supplied orange Jase J and jay logo. Windows executables contain icons from 16 to 256 pixels, so Explorer, the taskbar, the window and the tray share the same artwork. The macOS app and Dock icon use the orange logo; the top menu bar uses a white silhouette with a transparent background at Retina resolution.

The Windows panel has a light background, rounded sections, orange primary actions, two-line model and website rows, and a clearer first-run state. Native keyboard navigation, selectable activity details and per-monitor DPI scaling are retained. An embedded manifest enables current Windows control styles without an additional UI runtime.

The website protocol, model consent and local-only activity log are unchanged. Safari still requires SDK 0.5.2 or later. All executable packages remain unsigned as described in the repository README.

Validated with native Windows tests, executable resource loading, minimum/default layouts at 100%, 150% and 200%, and pixel checks for every macOS icon size and the white menu-bar silhouette. The release workflow additionally checks Windows, macOS and Linux, builds all five downloads on macOS, and verifies checksums before preparing the draft release.
