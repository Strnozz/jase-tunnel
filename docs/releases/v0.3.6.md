## Jase logo on every desktop

Includes the branding and Windows panel improvements described in [0.3.5](https://github.com/Strnozz/jase-tunnel/blob/main/docs/releases/v0.3.5.md): the orange J and jay logo on Windows, macOS and Linux, and its white silhouette in the macOS top menu bar.

Release builds now use the reviewed, checked-in Windows and Linux artwork without regenerating tracked files. x64 and ARM image resampling can differ slightly, so artwork checks compare visible pixels with a small rounding tolerance while continuing to verify the actual COFF resources, icon group and manifest byte for byte. This fixes the macOS packaging failure of the unreleased 0.3.5 tag. No desktop downloads were published for that tag.

The macOS app still generates its complete icon set and white Retina menu-bar silhouette from the original Jase logo. SDK 0.5.3 remains the companion npm package awaiting owner approval; no SDK changes are needed for this build correction.
